companion's independent hard blocker prevents only that companion from running;
it does not automatically block an otherwise runnable root. Active companion
work still holds the lane slot. Approved uncertainty can conservatively suppress
the affected unit.

The plan now states that distinction and requires a unit case for a runnable
root with an independently hard-blocked companion. This correction is resolved.
